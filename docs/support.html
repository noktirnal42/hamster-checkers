Before Filing

Small details make fixes faster.

  • Install the newest TestFlight or App Store build before reporting a fixed bug.
  • For Online 2P, sign in to Game Center on each device with different Apple IDs.
  • Use Refresh in the Online 2P panel if an active match or turn does not appear immediately.
  • Add a screenshot or short screen recording when it helps explain the behavior.
  • Do not post passwords, private Apple ID details, payment information, or personal contact data in public issues.

What to include for Game Center reports

Tell us whether the problem happened during sign-in, New Online, Auto-Match, Refresh, active match opening, or Resume Online. Include both devices and whether each player was able to see the same match.

What to include for rules reports

Describe the board state, whose turn it was, which piece moved, and whether a capture, multi-jump, king, undo, or no-move win looked wrong.
